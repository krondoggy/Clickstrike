# Castle Strike faction portrait atlases

These three original faction atlases provide one separate portrait for every playable unit. The earlier twelve-cell `portraits.png` atlas is retained. All images were generated with the built-in ImageGen tool, one call per atlas; no external game portrait assets were imported.

Each atlas has a 3-column × 3-row layout with no gutters, margins, borders, or text. Use `background-size: 300% 300%`; horizontal and vertical CSS background positions are `0%`, `50%`, `100%`.
