# Clickstrike

Browser idle clicker / base assault. Mine gold, start a battle, spawn troops, destroy the enemy base.

## Play

Open `index.html` (or a local static server). No build step.

1. **Mine Gold** and buy upgrades between fights.
2. **Start Battle** — your base (left) vs theirs (right).
3. **Spawn** Spearman / Archer / Knight with banked gold while the fight is live.
4. Win by reducing enemy base HP to 0. Lose if yours falls (cooldown; gold kept).

## Notes

Max 6 units per side. Enemy auto-spawns. Numbers are placeholders to tune.
